## 摘要
自主AI代理的兴起代表着用户与移动设备交互方式的重大范式转变。诸如MobileRun和Mobile-Use之类的框架能够自主导航Android应用程序并执行复杂的多步骤任务。为了解释用户界面，这些框架主要依赖Android无障碍（A11y）树，其次依赖视觉截图。在本文中，我们证明这种架构上对未净化无障碍元数据的依赖，连同视觉输入，导致了间接提示注入的系统性漏洞。我们表明，对抗性提示可以导致自主代理放弃其原始目标、违反上下文边界并执行未经授权的设备操作。我们的实证评估展示了在视觉隐藏和完全暴露的攻击场景中的目标劫持、上下文漂移和未经授权的操作。总体而言，MobileRun在Gemma4:31B下达到0.822的攻击成功率，而Mobile-Use与Qwen3.6:35B将其降至0.150，但并未消除上下文漂移或未经授权的操作。这些发现揭示了当前的移动代理框架未能强制执行语义上下文边界，将被动的环境文本视为可信指令。最后，我们提出了这些攻击的分类，并讨论了在移动代理架构中采用零信任输入验证、专用安全代理和严格上下文隔离的必要性。

## Abstract
The rise of autonomous AI agents represents a major paradigm shift in how users interact with mobile devices. Frameworks such as MobileRun and Mobile-Use can autonomously navigate Android applications and execute complex multi-step tasks. To interpret user interfaces, these frameworks rely primarily on Android accessibility (A11y) trees and secondarily on visual screenshots. In this paper, we demonstrate that this architectural dependence on unsanitized accessibility metadata, together with visual input, introduces a systemic vulnerability to indirect prompt injection. We show that adversarial prompts can cause autonomous agents to abandon their original objectives, violate context boundaries, and perform unauthorized device actions. Our empirical evaluation demonstrates goal hijacking, context drift, and unauthorized actions across visually hidden and fully exposed attack scenarios. In aggregate, MobileRun reaches an attack success rate of 0.822 with Gemma4:31B, while Mobile-Use with Qwen3.6:35B reduces this to 0.150 but does not eliminate context drift or unauthorized actions. These findings reveal that current mobile agent frameworks fail to enforce semantic context boundaries, treating passive environmental text as trusted instructions. Finally, we present a taxonomy of these attacks and discuss the need for zero-trust input validation, dedicated security agents, and strict context isolation within mobile agent architectures.

移动AI代理（如 MobileRun、Mobile-Use）能够自主导航 Android 应用并执行多步骤任务。它们理解 UI 主要依赖 **Android 无障碍（Accessibility, A11y）树**，辅以视觉截图。论文指出，这种架构依赖将**未净化的无障碍元数据**当作可信输入，构成一种**系统性间接提示注入（Indirect Prompt Injection）漏洞**：攻击者可在通知、网页、日历、联系人、隐藏无障碍节点乃至框架内部规划上下文（AppCard）中植入对抗性指令，使代理放弃用户原本目标、违反上下文边界，执行未经授权的设备操作（如打开设置、窃取 Build Number 等）。论文强调：当前框架**未能区分“可信用户意图”与“不可信环境内容”**，被动环境文本被错误地当作指令执行。

## 2. 论文提出的方法论

论文提出了一套**移动端间接提示注入攻击分类（taxonomy）与评估基准**，包含 9 个攻击向量（A1–A9）：

| 向量 | 攻击面 | 注入位置 |
|---|---|---|
| A1 | 通知注入 | 系统通知文本 |
| A2 | 同应用运行时覆盖层（如 Chrome 内覆盖） | 同应用覆盖层 |
| A3 | 跨应用运行时覆盖层 | Chrome 覆盖层（影响其他应用任务） |
| A4 | 应用内隐藏无障碍元数据注入 | 仅存在于 A11y 树的隐藏节点（人类不可见） |
| A5 | HTML 注入（网页条款） | 网页内容 |
| A6 | 日历描述注入 | 日历事件描述 |
| A7 | 笔记注入 | 便签正文 |
| A8 | 联系人注入 | 联系人备注字段 |
| A9 | AppCard 投毒（规划层注入） | MobileRun 的框架级规划上下文 |

上述向量覆盖三大攻击类别：**系统/运行时注入（A1–A3）、应用内容注入（A4–A8）、规划层注入（A9）**。A1–A8 使用统一对抗目标：劫持代理打开 Android 设置、检索 Build Number 并纳入响应；A9 则在 MobileRun 推理模式下测试 AppCard 内容能否引导代理执行未授权子目标。

**评估框架与模型：**

- 框架：MobileRun v0.6.0（支持 FastAgent/Reasoning 两种执行模式，各有 A11y-only 与 A11y+视觉配置）、Mobile-Use v3.3.0（多智能体模块化流水线）
- 模型：Gemma4:31B、Qwen3.6:35B

**核心指标（公式化定义）：**

- **攻击成功率 (ASR)**：代理完成对抗目标并在响应/日志中暴露攻击者要求结果的试验比例。
- **上下文漂移率 (CDR)**：代理将注入指令纳入主动推理、记忆或执行计划的试验比例（仅引用不受影响不算）。
- **未授权操作率 (UAR)**：代理执行至少一次朝向对抗目标的越权动作（如打开 Settings）的试验比例。

## 3. 实验设计

- **任务设计**：为每个向量设计良性用户任务（如查看通知、总结网页条款、读日历事件、读杂货清单、报告联系人“Mom”等），并植入对应注入载荷。
- **对比维度**：两框架 × 两模型 × 多种感知（A11y-only vs. 视觉辅助）/执行架构（直接执行 vs. 多智能体推理）配置；并对比不同攻击面（通知/覆盖层/网页/日历/笔记/联系人/隐藏节点/规划层）的易感性。
- **试验规模**：MobileRun 共 340 次试验（8 向量 × 4 配置 × 2 模型 × 5 轮 + A9 × 2 配置 × 2 模型 × 5 轮）；Mobile-Use 共 80 次试验（8 向量 × 2 模型 × 1 配置 × 5 轮）；每配置 5 次独立重复。

## 6. 论文的主要结论与发现

- **MobileRun + Gemma4:31B 最脆弱**：聚合 ASR₃ = 0.822、CDR₃ = 0.922、UAR₃ = 0.889。
- **Mobile-Use + Qwen3.6:35B 最鲁棒**：ASR₃ = 0.150、CDR₃ = 0.325、UAR₃ = 0.275（但仍未根除漏洞）。
- **应用内容注入（A4、A5、A7、A8）与规划层注入（A9）效果最强**：A9 在两种模型下均实现 ASR=CDR=UAR=1.0；A4（隐藏无障碍节点）对 Gemma4:31B 达 ASR₂=0.95。
- **运行时注入（A1–A3）效果不稳定**：A3 跨应用覆盖层最弱。
- **模型差异显著**：Qwen3.6:35B 整体比 Gemma4:31B 更抗攻击，但仍在多个应用内容向量上出现非零攻击成功率。
- **视觉增强并非可靠防御**：添加截图有时降低 ASR（如 Reasoning 模式下 Gemma4:31B 从 0.89 降至 0.62），有时反而升高（FastAgent 下 0.85→0.90），不能作为安全边界。
- **核心架构缺陷**：单纯增加推理阶段、多智能体架构或视觉输入，均无法从根本上解决“可信指令 vs. 不可信环境内容”的隔离问题。

## 7. 优点

- **首个系统性聚焦 A11y 攻击表面的研究**：补足此前仅评估任务完成度或一般安全性的空白，明确指出无障碍树是“可利用的信任边界”。

- **细粒度失败阶段分析**：ASR/CDR/UAR 三元区分“观察→推理漂移→越权执行→完全成功”的不同妥协层级，避免将部分失败简单归为成功/失败。
