## 摘要
随着大语言模型（LLM）智能体越来越多地调用外部工具并与真实世界系统交互，不安全的行为可能会对外部状态、用户数据和下游服务造成不可逆的后果。近期的运行时防护栏通过在执行前检查提议的行动来缓解此类风险，但许多仍是被动式的：它们主要评估当前行动的明显安全性，缺乏对风险如何在轨迹上演变的显式建模。这一局限为长周期风险留下了关键盲区，其中个别看起来无害的行动可能逐渐将智能体推向危险状态。为此，我们提出DreamGuard，一种围绕风险感知世界模型构建的LLM智能体主动防护栏。该世界模型在轨迹上维护一个紧凑的循环潜在状态，并预测未来潜在状态，DreamGuard从中提取即时危险和前兆风险证据，然后在执行前将这些多时间尺度信号融合为干预决策。在四个基准和一个在线防护栏评估上的实验表明，DreamGuard优于通用、被动式和主动式防护栏基线，在所评估的防护栏中实现了最佳的安全性-效用权衡，并保持了每次调用平均25毫秒的端到端延迟。

## Abstract
As large language model (LLM) agents increasingly invoke external tools and interact with real-world systems, unsafe actions may cause irreversible consequences on external states, user data, and downstream services. Recent runtime guardrails mitigate such risks by checking proposed actions before execution, but many remain reactive: they primarily assess the apparent safety of the current action, lacking an explicit model of how risk evolves across the trajectory. This limitation creates a critical blind spot for long-horizon risks, where individually benign-looking actions can gradually drift the agent toward hazardous states. In response, we propose DreamGuard, a proactive guardrail for LLM agents built around a risk-aware world model. The world model maintains a compact recurrent latent state over the trajectory and predicts future latent states from which DreamGuard derives immediate-hazard and prefix-risk evidence. It then fuses these multi-horizon signals into intervention decisions before execution. Experiments across four benchmarks and an online guardrail evaluation show that DreamGuard outperforms generic, reactive, and proactive guardrail baselines, achieves the best safety-utility trade-off among evaluated guardrails, and maintains an average end-to-end latency of 25 ms per call.

# DreamGuard：通过风险感知世界模型为LLM智能体提供高效运行时防护栏

## 1. 核心问题与整体含义（研究动机与背景）

*   **背景**：LLM 智能体越来越多地被赋予调用外部工具、与真实世界系统交互的能力，其输出行为会直接影响外部状态、用户数据和下游服务。一旦执行不安全动作，后果可能是不可逆的（如删除文件、泄露凭据、调用未授权 API）。
*   **核心问题**：现有运行时防护栏（Runtime Guardrail）大多属于**反应式（Reactive）**——它们只评估当前提议动作的表面安全性，**缺乏对风险在轨迹（Trajectory）中如何演变的显式建模**，因而对**长周期风险（Long-Horizon Risks）**存在关键盲区：单个步骤看起来无害，但逐步累积最终导向危险状态（例如：先定位内部文件 → 移动到工作区 → 创建公开分享链接 → 机密数据泄露）。
*   **整体含义**：本文提出 **DreamGuard**，首个围绕**风险感知世界模型（Risk-Aware World Model）**构建的**主动式（Proactive）**运行时防护栏，旨在让智能体在执行动作**之前**就能预测多时间尺度的风险并做出干预决策，在保证安全的同时维持极低的运行延迟。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
DreamGuard 的核心是**将世界模型从"预测通用未来状态"转向"预测风险相关信息"**：用轻量级 GRU 循环动力学维护一个固定维度的潜在状态（Latent State），编码轨迹历史；在该潜在状态上预测后继状态，并从中提取两类互补的风险证据——**即时危险（Immediate-Hazard）**与**前缀风险（Prefix-Risk）**——融合后做出校准的干预决策。

### 2.2 问题形式化
- 在每个步骤 t，防护栏接收：任务指令 e、当前观测 o、提议动作 a 以及轨迹历史 H。
- 输出决策 d ∈ {PASS（放行）, HOLD（低置信度或累积风险时中断并保守干预）, BLOCK（阻止执行）}。

### 2.3 风险感知世界模型（六个核心组件）
- **序列模型**：h_t = f_θ(h_{t-1}, z_{t-1}, a_{t-1})，GRU 循环转移。
- **表征模型（后验）**：z_t ~ q_θ(z_t | h_t, o_t)，推断当前随机潜状态。
- **动力学预测器（先验）**：ẑ_t ~ p_θ(ẑ_t | h_t)，预测后继潜状态。
- **观测预测器**：ô_{t+1} = g_θ^{obs}(s_{t+1})，在嵌入空间预测后继观测（辅助训练目标）。
- **即时危险预测器**：ℓ_t^{haz} = g_θ^{haz}(ŝ_{t+1}, a_t, e)，预测当前动作是否直接触发危险。
- **前缀风险预测器**：ℓ_t^{pre} = g_θ^{pre}(ŝ_{t+1}, a_t, e)，预测累积长周期风险。

### 2.4 两阶段训练
1. **世界模型预训练**：优化预测损失（嵌入空间余弦相似度）、动力学损失与表征损失（带 stop-gradient 和 free-bits 的 KL 散度），学习通用循环潜动力学。
2. **风险监督训练**：用即时危险标签（y^haz）和**指数衰减的前缀风险软标签**（y^pre = exp(-(t_haz - t - 1)/ρ)）对未冻结的预测头进行监督，保持 GRU 转移核心固定，使潜状态**专门保留对风险判别有效的信息**。

### 2.5 多时间尺度风险估计与干预
- **前缀风险时序聚合**：对前缀风险分数计算**指数移动平均（EMA）**与**滑动窗口均值**，保留持续弱证据与瞬态上升证据。
- **Noisy-Or 融合**：将即时危险分数、EMA 分数、窗口分数融合为综合风险分 S_t。
- **Split-Conformal 校准**：在安全轨迹上校准两个阈值——λ_block（对即时危险分数，更严格）与 λ_hold（对融合分数，目标轨迹级误报水平 α）。
- **干预规则**：若 p^haz ≥ λ_block → BLOCK；若 S_t ≥ λ_hold → HOLD；否则 PASS。

## 6. 主要结论与发现

*   **离线效果**：DreamGuard 在全部四个基准上取得最高或次高的 F1/SR，且 FPR 保持较低。SafetyDrift 上 F1 = 96.4%、SR = 96.3%、FPR = 3.7%。
*   **时序干预优势**：在 SafetyDrift 上 PHIR = 96.3%、MAS = 3.63，证明能在危险动作**之前**平均提前 3.63 步发出干预，显著优于反应式与主动式基线。
*   **极致低延迟**：平均端到端延迟 **0.025 秒/次调用**，比 TRACES（0.081s）快 3.3 倍，比 GuardAgent（6.655s）快 250.6 倍，比 SafePred（7.686s）快 424 倍。
*   **在线权衡最优**：在真实工具调用环境中，DreamGuard 达到安全率 72.92%、效用率 90.38%，**超越由所有基线形成的安全-效用帕累托前沿**（TRACES 为 56.25%/90.38%，TS-Guard 为 66.67%/90.38%）。
*   **消融显著**：去掉循环世界模型 → FPR 升至 73.7%；去掉即时危险预测器 → F1 下降 30.8 个百分点；去掉世界模型预训练 → FPR 高达 92.0%；去掉风险监督训练 → 过于保守（SR 仅 64.1%）。所有组件对安全-效用平衡缺一不可。

## 7. 优点（方法与实验设计的亮点）

1. **风险感知的轻量世界模型**：用 GRU 循环动力学与固定维度潜状态代替 LLM 推理，既解决了轨迹增长的上下文瓶颈，又保留了风险判别所需的历史信息，实现"高效 + 主动"兼得。
2. **风险感知而非通用预测**：通过两阶段训练（先学通用动力学、再用风险标签塑造潜状态），使预测的后继状态携带危险转换的证据，避免"预测与安全评估分离"导致的证据缺失。
3. **多时间尺度信号融合**：即时危险（当前边界）与前缀风险（累积证据）通过 EMA + 滑动窗口 + Noisy-Or 融合，配合 Split-Conformal 阈值校准，可以"提前警告而不过度误报"。
4. **可校准的干预决策**：用安全轨迹的逐轨最大值做 split-conformal 校准，从理论上控制了轨迹级误报率，而非启发式调参。
5. **评估设计严谨**：引入 PHIR/MAS 时序指标揭示"是否及时干预"而非只看最终拦截；标注稳定性审计 + 重复运行 + Wilcoxon 检验增强了结论可信度。
6. **部署友好**：25ms 的延迟使其能嵌入真实智能体的每一步动作前钩子，具备实用价值。

## 8. 不足与局限

1. **训练与校准数据单一**：仅在 SafetyDrift 上训练与校准，其他基准为零样本迁移；面对显著分布偏移时性能可能受限，论文也承认轻量重校准可能进一步优化。
2. **在线评测规模有限**：在线安全-效用评估仅基于 100 例 ASSE 子集，样本量偏小，结论的泛化性需更大规模验证。
3. **风险评估与干预分离**：DreamGuard 目前只做"是否干预"，**不生成安全替代动作**，干预时会造成任务中断；论文将动作修订列为未来工作。
4. **步骤级标注的固有噪声**：虽然做了双人评审审计，但 ASSE-Security 上精确一致率仅 79.6%，边界模糊性可能影响 PHIR/MAS 的精确性。
5. **域间 FPR 波动**：在 AgentDojo 上 FPR 达 29.4%，说明跨域迁移时阈值不完全适配，仍存在误报风险。
6. **未报告训练成本细节**：未明确给出预训练与风险监督训练的具体 GPU 时长，不利于复现成本评估。
