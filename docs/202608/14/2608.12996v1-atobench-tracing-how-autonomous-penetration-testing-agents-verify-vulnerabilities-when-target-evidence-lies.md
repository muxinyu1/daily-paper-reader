## 摘要
自主渗透测试代理依赖于目标响应。这些响应既引导后续行动，也引导最终报告。因此，欺骗性响应可以同时改变攻击轨迹和代理的验证过程。然而，最终报告很少揭示代理如何解释冲突证据、改变方向、决定停止，或将观察转化为漏洞声明。我们提出了 ATOBench，一个使这一验证过程可观察的评估框架。ATOBench 在运行时注入注册的响应转换，并将每个转换后的场景与同一环境下的原始场景配对。每个配对在第一个受影响的响应处对齐。随后，源关联重建跟踪后续行动、证据恢复、停止和报告支持。三个固定的观察契约覆盖利用证明、资源所有权和可重用工件。我们在超过 450 个场景上评估了五条模型路线。分析表明，活动增加可能会掩盖断裂的验证链，而成功恢复取决于找到可用证据并在报告中保留它。ATOBench 将欺骗性目标观察转化为自主渗透测试中证据处理的可复现探针。这种过程级视角通过揭示不可信观察如何塑造行动、验证和报告，将进攻性渗透测试代理评估扩展到最终结果之外。

## Abstract
Autonomous penetration-testing agents rely on target responses. These responses guide both subsequent actions and the final report. A deceptive response can therefore redirect both the attack trajectory and the agent's verification process. However, final reports reveal little about how an agent interprets conflicting evidence, changes course, decides to stop, or turns observations into a vulnerability claim. We introduce ATOBench, an evaluation framework that makes this verification process observable. ATOBench injects registered response transformations at runtime and pairs each transformed episode with a native episode under the same environment. Each pair is aligned at the first affected response. A source-linked reconstruction then follows later actions, evidence recovery, stopping, and report support. Three frozen observation contracts cover exploit proof, resource ownership, and reusable artifacts. We evaluate five model routes over 450 episodes. The analysis shows that increased activity can mask a broken verification chain, while successful recovery depends on finding usable evidence and preserving it through reporting. ATOBench turns deceptive target observations into a reproducible probe of evidence handling in autonomous penetration testing. This process-level view extends offensive pentest agent evaluation beyond final outcomes by revealing how untrusted observations shape actions, verification, and reporting.

### 2.1 核心思想：对抗性目标观测（ATO）与配对对比

- **ATO 的定义**：在目标执行完请求之后、代理观察到响应之前，对选定的目标响应进行受控修改。不修改出站请求、目标代码、目标状态、漏洞、提示词或可用工具。

### 2.4 证据重建与评估管线（三层分析）

1. **确定性重建**：将代理事件、AOU 记录、动作与返回工件链接，生成注册证据标签 Ei；
2. **身份盲化的 Agent-as-Judge**：评估最终报告是否闭合注册发现（Ci）及声明是否被轨迹支持（Si）；
3. **轨迹 Judge**：独立评估 Verification Control（验证控制）、Stop Decision（停止决策）、Report Grounding（报告依据）。

### 2.5 主要指标

## 6. 论文的主要结论与发现

1. **SQLi 验证在所有模型上崩溃**：混合 GV 从 44.0% 降至 0%，配对差异为 −44.0 个百分点（95% CI [−54.7, −33.3]）；五个模型的 ATO 行全部为 0%，呈现跨模型一致性的"证据恢复瓶颈"。
2. **不同契约在验证链的不同位置断裂**：Basket 瓶颈在于适应后的证据恢复（25/39 恢复，22/25 进入支持报告）；JWT 瓶颈在于证据到报告的传播（45 个证据阳性中 44 个关闭支持报告）；SQLi 瓶颈在直接证明的恢复（19 个尝试替代策略，0 个恢复主证据）。
3. **更多活动 ≠ 有效验证**：SQLi ATO 轨迹中位增加 14 个动作、9 次重复、5 次端点切换、6 次载荷族切换，但未恢复任何有依据的验证；活动增多反而可能掩盖验证链断裂。
4. **保留率差异显著**：Basket 保留率 61.9%，JWT 79.2%，SQLi 0%，说明证据的位置与持久性（直接证明 vs. 可复查关系 vs. 可重新获取工件）决定欺骗对验证过程的影响模式。

## 7. 优点

- **过程级评估范式**：超越最终结果，首次系统追踪"观察→动作→证据恢复→停止→报告"的完整验证链。
- **受控的因果对比**：配对 Native-ATO 设计隔离了响应变换这一单一干预，锚点对齐使过程比较具有可解释性。
- **AOU 抽象**：选择器/变换/剂量的形式化封装，配合入场重放测试与恢复/矛盾控制路径，使欺骗干预可复现、可审计。
- **严格的评估协议**：身份盲化、双 Judge + 仲裁、人类专家审计、

- 高可靠性的人机协同审计流程，以及入场重放测试对 AOU 正确性的前置保障。
- **指标设计**：GV 将“可注册证据 + 报告闭合 + 轨迹支持”三者绑定，杜绝了“编造报告”或“乱撞成功”被误判为有效验证的可能；保留率则直接刻画了模型在欺骗条件下维持原有验证能力的能力。
- **实验的高可控性**：只在响应层面做最小干预（不触发出站请求、目标代码和漏洞），配合锚点对齐的配对设计，使得任何过程差异都可归因于 AOU 的变换，而不是环境或提示词的偶然差异。

## 8. 缺点与局限性

- **目标环境单一**：全部实验基于 OWASP Juice Shop 一个应用。虽然三个契约覆盖了不同证据结构（直接证明、资源归属关系、可重新获取工件），但无法覆盖真实目标系统中更广泛的漏洞类型、协议交互与状态机复杂度。
- **样本量偏紧**：每个模型 × 契约组合仅 15 个匹配配对。论文虽提供了 paired-bootstrap 置信区间，但对低频行为（如某种罕见恢复路径）的统计功效有限，难以支撑更细粒度的结论（如“某个模型在特定契约上的恢复能力排名”）。
- **固定预算弱化了对“晚期恢复”的观测**：最大工具调用次数（40/70）和时间限制（2400/3000 秒）可能截断了那些能够经过更多探索后才意识到被欺骗并重新建立证据的轨迹，论文自己也承认这一点。
- **变换的离散性与可逆性**：AOU 的变换都以“有限剂量 + 恢复路径”设计（如 Basket 只欺骗前两次、JWT 只欺骗一次），这更适合度量“能否在干扰后恢复”，却无法建模真实世界持续性披露欺骗或自适应响应攻击。
- **仅覆盖“成功响应被篡改”一种欺骗类型**：论文没有测试失败响应（如错误代码被改为成功）、协议级中断（如连接重置、超时）、注入到非锚点响应的干扰等，因此结论的推论范围应谨慎限定在“证据被扭曲但目标保持可用”这一谱系。
- **对底层模型的封闭性**：所有模型路线都通过统一的 Claude Code 轨道运行，这保证了公平，但也意味着结论可能受该框架在规划、记忆、工具解析等方面实现细节的约束。若换成其他代理框架（如通用 ReAct 循环、不同工具描述格式），量化的数值可能发生变化。
- **资源透明度不足**：论文未披露各模型 API 调用的成本、推理基础设施或运行时间分布，这不利于读者评估该评估体系的复现成本与可扩展性。

## 9. 作者观点与评述（延伸思考）

- **关于“观察即战场”**：论文本质上把渗透测试中“目标响应”重新定义为一个不可信的传感器，而不是透明的真相窗口。这在真实防御场景中相当合理——欺骗、蜜罐、响混淆已是现实威胁，而 LLM 代理往往因训练时的“工具结果可信”假设而缺乏对矛盾的显式建模。
- **验证链断裂的位置可能比发生率更重要**：三类契约展示了不同的失败模式——SQLi 是“无法拿回直接证据”，Basket 是“能恢复但需要额外步骤”，JWT 是“证据可恢复但报告链脆弱”。这意味着评估不能只看一个成功率数字，更需要区分薄弱环节，以便为代理设计提供定向改进。
- **活动量上升并非验证信号**：在 SQLi 的 ATO 轨迹中，代理更积极、更多样地切换载荷和端点，却没有任何有依据的验证得到闭合。这一发现给“以动作数量衡量探索充分性”的既有评估方法敲响警钟，也提示未来代理需要在“探索的广度”和“证据的确信度”之间做显式权衡。
- **欺骗性响应可以作为一种有效的对抗防御评测工具**：ATO 框架不仅用于评估代理，也可以反过来用于对防御机制进行量化——当网络欺骗介入时，代理的能力衰减多少、哪些环节最先断裂、哪些模型更容易被诱导到错误结论，这些都可以为防御方提供情报。
- **对“可审计的自主渗透测试”的启发**：若要实现可在安全合规流程中被信任的自主渗透测试代理，论文的三要素（确定性重建、证据标签、报告依据审计）几乎可以成为标准要求——我们不仅需要知道代理“做了什么”，还要知道“它凭什么相信目标响应”。

## 10. 结论（论文主旨与贡献总结）

ATOBench 通过引入对抗性目标观测（ATO）与配对 Native/ATO 对比实验，首次把自主渗透测试的评估焦点从“能否找到漏洞”前移到“在目标证据被扭曲时，验证链能否闭合”。论文的贡献是多层次的：

1. 在方法上，提出了可复用的 AOU 抽象与确定性过程重建管线，使欺骗性干预可形式化、可复现、可审计；
2. 在实验上，通过 225 个配对回合展示了三个代表性的验证链断裂模式，并证明“活动增加并不等于验证能力”；
3. 在指标上，给出 GV 与保留率这种同时要求证据、报告与轨迹三者一致的严格度量，避免了常见评测中“结果正确但理由错误”的幻觉漂移。

论文也清醒地限定了其适用范围：单目标、固定代理框架、有限预算、有限变换类型。面向未来，这项工作为自主渗透测试代理指明了一个新的能力维度——**在不可信观测下的证据稳健性**，并提供了可靠的测量工具来引导研究攻关。
