## 摘要
基于大型语言模型（LLM）的智能体越来越多地被用于复杂任务，如软件测试和网络安全评估。尽管这些智能体展现出令人印象深刻的能力，但它们的行为难以理解、解释和分析。现有的评估主要关注任务成功率和执行轨迹，对智能体所采用策略的洞察有限。我们提出了ATLAS（用于智能体轨迹分析与策略发现的自动机学习），一种从智能体轨迹中恢复可解释行为模型的方法。ATLAS结合了轨迹抽象与自动机学习，以推断捕获观察到的智能体-环境交互策略的有限状态模型。这些模型提供人类可解释的洞察，并支持对重复行为、决策点、成功完成任务路径和失败循环的自动化分析。作为概念验证，我们将ATLAS应用于由基于LLM的渗透测试智能体生成的轨迹。生成的模型揭示了利用脆弱机器的高级行为策略，这些策略仅从原始执行轨迹中难以识别。我们讨论了学习到的行为模型如何支持可解释性、模型引导的探索、审计以及对智能体系统的分析。我们进一步展示了从强大的前沿模型到紧凑语言模型的基于符号模型的知识迁移。此外，我们展示了模型转换如何在包含12台脆弱机器的渗透测试案例研究中推导出智能体行为的简洁解释。ATLAS强调了模型驱动工程的一个新机会：将智能体轨迹转换为显式行为模型，从而能够系统性地理解和分析原本不透明的AI智能体。

## Abstract
Large Language Model (LLM)-based agents are increasingly used for complex tasks such as software testing and cybersecurity assessment. While these agents demonstrate impressive capabilities, their behavior is difficult to understand, explain, and analyze. Existing evaluations focus mainly on task success and execution traces, offering limited insight into the strategies employed by the agent. We present ATLAS (Automata Learning for Agent Trajectory Analysis and Strategy Discovery), an approach for recovering interpretable behavioral models from agent trajectories. ATLAS combines trace abstraction with automata learning to infer finite-state models that capture observed agent-environment interaction strategies. These models provide human-interpretable insights and support automated analyses of recurring behaviors, decision points, successful task-completion paths, and failure loops. As a proof of concept, we apply ATLAS to trajectories generated by an LLM-based penetration-testing agent. The resulting models expose high-level behavioral strategies for exploiting vulnerable machines that are difficult to identify from raw execution traces alone. We discuss how learned behavioral models can support explainability, model-guided exploration, auditing, and analysis of agentic systems. We further demonstrate symbolic model-based knowledge transfer from powerful frontier models to compact language models. In addition, we show how model transformations can derive concise explanations of agent behavior in a penetration-testing case study comprising 12 vulnerable machines. ATLAS highlights a new opportunity for model-driven engineering: transforming agent trajectories into explicit behavioral models that enable systematic understanding and analysis of otherwise opaque AI agents.

### 2. 方法论：核心思想、关键技术细节与算法流程

ATLAS 的完整流程分为三个阶段：

#### 阶段一：轨迹收集（Trace Collection）
- 在特定任务环境中执行智能体，记录其与环境（如命令执行、工具调用）的完整交互序列，作为学习行为的原始输入。

#### 阶段二：轨迹抽象（Trace Abstraction）
- **目的**：解决“词汇鸿沟”问题——原始轨迹由具体命令和自由文本输出构成，无法直接用于自动机学习。
- **方法**：完全由 LLM 驱动的三阶段流水线（无需人工设计抽象函数）：
  1. **LLM 分类（LLM Categorization）**：将批量的交互记录呈现给 LLM，要求将每个具体动作映射为“动作类别（可选加目标）”（如 `cmd.exec (sudo -l)`），将每个观测输出映射为“语义值_目标”格式的类别（如 `DISCOVERY_SUID`、`EXPLOITABLE_FILE`）。
  2. **类别归一化（Category Normalization）**：汇总所有运行的类别标签，通过 LLM 合并语义等价的冗余类别，形成紧凑的符号字母表。
  3. **逐轨迹赋值（Per-trace Assignment）**：将完整交互序列与归一化后的类别词汇表交给 LLM，生成结构化的抽象轨迹序列，并采用重试机制处理格式错误。
- 该抽象是有损的，但保留了行为意图，能适应不同任务和环境，且分类赋值阶段可由较小的模型完成，成本较低。

#### 阶段三：自动机学习（Model Learning）
- **算法**：采用 **Alergia**（一种基于状态合并的被动学习算法），实现为 AALpy 库中的马尔可夫链学习版本。算法将抽象轨迹组织成树，通过迭代合并行为上等价的状态节点，并归一化转移概率，最终生成一个**带标签的抽象马尔可夫链（MC）**。
- **状态标签**：每个状态标记为（抽象动作类别，观测类别）对，并可在终点附加成功/失败标签。
- **模型特点**：MC 自动检测潜在状态（latent states），不要求抽象观测满足马尔可夫性，能捕获观察历史中的相关信息。

#### 下游模型驱动工程应用
- 学习到的 MC 可支持多种分析与变换：
  - **知识迁移（Knowledge Transfer）**：从 MC 中提取策略摘要，或以动态遍历方式引导较弱模型执行任务。
  - **解释模型提取（Explanation Extraction）**：通过路径提取、剪枝和强连通分量（SCC）折叠，将较大 MC 压缩为聚焦成功路径的简洁 DAG 模型。

### 3. 实验设计：数据集、Benchmark 与对比方法

- **应用域与基准**：以 HackingBuddyGPT（LLM 驱动的渗透测试智能体）为对象，在 `Got Root?` 基准的 **12 个（共 13 个，排除不支持交互式 shell 的第 4 个场景）易受攻击的 Linux 虚拟机** 上进行实验。
- **轨迹生成**：使用 DeepSeek V4 Flash（非推理模式，128K 上下文）在每个 VM 上执行 **20 次**渗透测试（20 回合上限），并利用同一模型生成抽象符号轨迹，在末尾附加成功/失败标签。
- **对比与迁移模式**：
  - **基线（Baseline）**：无任何提示辅助的执行器模型（ministral-8b 或 ministral-14b）。
  - **Common Path**：由算法分析 MC 提取“最常导致成功的步骤”。（无知识 LLM 参与）
  - **Minimal**：用知识 LLM（DeepSeek V4 Pro）从 MC 摘要中生成 2–3 步简洁策略。
  - **Guided**：知识 LLM 生成更详细的结构化指导（一般策略 + 最多 5 个具体步骤 + 探索建议）。
  - **Dynamic**：在渗透测试过程中，根据学习到的 MC 状态同步跟踪，为执行器 LLM 逐步提供下一步建议。利用一个廉价的分类器 LLM（即执行器自身）将具体（命令，观测）对映射到已知类别，并推进 MC 状态。支持防重复机制与死端检测。
- **评估方式**：每个转移模式对每个 VM 执行 5 次渗透测试，统计“root 成功次数/总运行次数（Roots/Runs）”、“成功率（Success Rate）”以及“被成功利用的 VM 数量（VMs Exploited）”。

### 6. 主要结论与发现

- **行为模型可恢复性**：ATLAS 能从原始轨迹中恢复紧凑的、可解释的 MC 行为模型，这些模型揭示了侦察阶段、关键决策点、循环与失败模式。
- **知识迁移有效性**：
  - 动态模式（Dynamic）最为有效：对于 ministral-8b，成功率由基线 5.0% 提升至 28.3%，被利用的 VM 数量从 2 个增加至 4 个（3、7、8、13 号）；对于 ministral-14b，成功率由 1.7% 提升至 38.3%，被利用 VM 数从 1 个增加至 6 个（2、3、5、7、8、13 号），即解决了基准中 50% 的任务。
  - 摘要式提示（Minimal/Guided）对 14b 有效，但对 8b 提升微弱；Common Path 模式对 8b 反而造成负面影响，说明小型模型难以遵循多步指令。
  - MC 驱动的“单步指导 + 符号状态跟踪”模式能有效弥补小型模型的状态跟踪缺陷。
- **解释模型可提取性**：通过 DAG 抽取和剪枝折叠，可以将 57/41 状态的 MC 压缩到 7 个状态，简洁呈现通往成功的关键路径。
- **总体判断**：学习到的 MC 不仅仅是描述性记录，而是保留了可操作、可复用的符号知识，支持模型驱动的探索与规划。

### 7. 优点

- **方法论创新**：首次将 LLM 驱动的语义抽象与随机自动机学习（Alergia）结合，从轨迹中恢复行为模型，突破了以往依赖人工抽象或仅关注任务成功率的局限。
- **完全自动化**：无需人工标注或预定义抽象函数；“最小参数 + 全自动化”流程使之易于推广到新任务和领域。
- **无需马尔可夫性假设**：相较 Trace2Chain 和 ProbGuard，ATLAS 通过自动机学习推断潜在状态，能够捕获历史依赖行为。
- **下游应用价值明确**：动态迁移模式对小型模型能力提升显著（最高 38.3% 成功率），展示了模型驱动规划 + AI 执行的混合架构的潜力。
- **模型解释直观**：图 1、图 3 中的 MC 与 DAG 高度直观，支持分析人员直接理解行为模式。
- **可复现性**：提供了完整的手工制品——复现包（代码、抽象轨迹、具体轨迹、模型）托管于 Figshare。

### 8. 不足与局限

- **领域单一**：仅在渗透测试场景（Linux 提权漏洞）中验证，对通用性（web 导航、软件工程等）的论证不足。
- **实验规模有限**：每场景仅 20 条轨迹，模型对低概率分支覆盖不足；迁移实验每组仅 5 次运行，结论缺少统计保障。
- **缺乏消融与基准对比**：未深入分析抽象质量对学习结果的影响，未与其他轨迹分析模型（如 Trace2Chain、ProbGuard、基于决策树的抽象）进行量化对比。
- **潜在偏差**：用于提供“知识总结”的 DeepSeek V4 Pro 与训练数据生成模型 DeepSeek V4 Flash 同源，可能存在家族偏差；分类器 LLM 与执行器模型同源，存在自我确认风险。
- **抽象信息损失**：对观测信息的“价值”判定依赖 LLM，某些关键上下文可能被错误归类；在解释模型中重要行为可能被混合进 SCC（如 Scenario 13 中读取 admin_on_vac.txt 被折叠进 11 状态的 SCC），影响解释精度。
- **伦理与安全局限**：论文虽提及了依赖已有工作（HackingBuddyGPT 的伦理讨论），但对恶意利用风险、潜在攻击面（双 LLM 指令注入、动态 MC 引导被劫持）等安全评估不足。
- **可扩展性存疑**：对长轨迹、跨任务泛化、大型抽象字母表下 Alergia 的可扩展性尚未验证，说明未来需要定义“行为模型有用性”的系统性标准。
