## 摘要
检索增强生成（RAG）显著提升了大型语言模型（LLM）的性能，但这些系统仍易受知识投毒攻击，即检索文档中的错误信息可能影响模型的最终输出。值得注意的是，LLM可能正确检测到某文档包含错误信息，却仍然受其影响。先前工作通过Cordon原则解决了这一漏洞，该原则阻止负责最终答案合成的模型直接访问原始证据。虽然有效，但这种严格隔离可能带来大量计算开销。在本工作中，我们提出一个改进的安全原则：只有具备慎思式系统2推理能力的代理才能访问不可信文档。为评估该原则，我们引入了量化错误信息检测与下游影响之间差异的新指标。随后，我们使用这些指标实证比较了最先进的推理语言模型与标准语言模型。结果表明，具备推理能力的模型对受损证据的鲁棒性显著更强，且无需Cordon原则所强加的严格隔离。这些发现为我们的改进原则提供了实证支持，并为安全RAG系统设计提出了更实用的基础。

## Abstract
Retrieval-Augmented Generation (RAG) has significantly enhanced the performance of large language models (LLMs), yet these systems remain vulnerable to knowledge-poisoning attacks, in which misinformation in retrieved documents can influence the model's final outputs. Notably, an LLM may correctly detect that a document contains incorrect information while nevertheless being influenced by it. Prior work has addressed this vulnerability through the Cordon Principle, which prevents models responsible for final answer synthesis from directly accessing raw evidence. Although effective, this strict isolation can introduce substantial computational overhead. In this work, we propose a refined security principle: only agents capable of deliberative System 2 reasoning may access untrusted documents. To evaluate this principle, we introduce novel metrics that quantify the discrepancy between misinformation detection and downstream influence. We then empirically compare state-of-the-art reasoning language models with standard language models across these metrics. Our results show that reasoning-capable models are substantially more robust to corrupted evidence, without requiring the strict isolation imposed by the Cordon Principle. These findings provide empirical support for our refined principle and suggest a more practical foundation for secure RAG system design.

## 1. 论文核心问题与整体含义

- **研究背景与动机**：检索增强生成（RAG）通过外部知识增强了LLM的性能，但也引入了知识投毒攻击的漏洞——检索文档中的刻意错误信息可能污染最终输出。先前研究发现了一个关键现象（"monitoring-control gap"）：**模型即使成功检测到文档中的错误信息，仍然会在答案合成过程中受其影响**。
- **既有方案的局限**：Cordon原则通过禁止最终答案合成模型直接访问原始证据来防御该漏洞，虽然有效但引入了高计算开销并限制了系统灵活性。
- **本文的核心主张**：提出一个改进的安全原则——**只有具备系统2（deliberative）推理能力的代理才允许访问不可信文档**，而仅依赖系统1（联想匹配）的代理必须与不可信内容隔离。作者将该原则界定为经验验证目标而非新防御方法。

## 2. 方法论

- **核心思想**：利用具备系统2推理能力的模型（如DeepSeek-Reasoner）在检测到错误后能有效抑制其影响，因此无需Cordon原则的严格隔离。
- **安全原则**："Only agents capable of System 2 thinking may access untrusted documents"——将文档访问权限与代理的推理能力挂钩。
- **新指标1：Cordon Rate（C）**：
  - 定义：模型检测到被投毒文档（detected）**且**最终答案仍受其影响（influenced）的联合概率，即 C = P(detected ∧ influenced | valid instance)。
  - 强调：这是联合概率而非条件概率，衡量全有效样本中的绝对残留失败率。
  - 流程：给模型提供检索上下文（含注入的投毒文档），要求模型逐步推理、检查错误信息、给出最终答案；再由独立审判模型判定（a）是否检测到错误，（b）最终答案是否与正确答案矛盾。
  - 有效性过滤：剔除无上下文时也无法答对的样本，以隔离模型内在知识缺陷的影响。
- **新指标2：Contamination Rate（T）**：
  - 定义：比较同一模型在两种条件下的表现——M1（提供含投毒文档的上下文，但明确指示忽略文档、仅依赖参数知识）与M2（无任何上下文）。若M1受影响且M2不受影响，则记为污染。
  - 目的：控制参数知识混淆，分离出上下文（检索文档）对模型的"自动化"影响，即使被明确要求忽略也依然存在。
- **投毒文档生成**：采用**故意朴素的投毒策略**——生成正确答案的矛盾句，扩展为约500字连贯且看似可信的段落，再由审判模型确认段落确实与正确答案矛盾。朴素设计是为了证明监控-控制差距是根本性结构缺陷，而非高级攻击的产物。

## 6. 主要结论与发现

- **RQ1（系统2能力）**：DeepSeek-Reasoner在SciFact和FiQA上Cordon Rate为0，而DeepSeek-Chat分别为0.175和0.025。两个模型在MS-MARCO上均为0。结论：**推理模型可安全访问不可信文档且不显著受其影响**。
- **RQ2（无系统2模型的脆弱性）**：在SciFact上，DeepSeek-Chat的Contamination Rate为0.25，即便被明确指示忽略上下文仍受污染；DeepSeek-Reasoner为0.10，降低过半。FiQA上Chat为0.10、Reasoner为0。结论：**不具备系统2能力的模型确实存在隐式上下文污染**，推理能力可显著缓解甚至消除该影响。
- **RQ3（差距显现的条件）**：监控-控制差距在**知识密集型、科学事实核查类任务**（SciFact）上最明显，在开放域简单检索（MS-MARCO）上基本不显现。攻击成功率也最高在SciFact（Chat: 0.265 vs Reasoner: 0.154）。结论：**任务复杂度和知识密度是放大监控-控制差距的关键因素**。
- **总体意义**：为"仅系统2代理可访问不可信文档"的安全原则提供了实证支持，说明该原则可在不牺牲安全性的前提下避免Cordon原则的严格隔离开销。
