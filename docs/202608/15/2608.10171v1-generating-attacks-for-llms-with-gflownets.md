## 摘要
大型语言模型（LLMs）的快速发展促进了其在各个领域的广泛集成与应用。然而，这一日益增长的趋势也引入了显著的安全漏洞，需要识别和缓解因恶意利用而产生的缺陷。红队评估通过多样化的对抗性输入来评估模型的鲁棒性，对于揭示安全风险和实施应对措施至关重要。目前，红队测试要么由专家手动进行，要么使用预定义的攻击数据集自动进行。然而，手动测试仍然耗时，而现有的自动化方法由于对固定数据集的固有依赖而缺乏创造性。在本研究中，我们提出了一种自动化、独立于人类且自适应的红队测试方法，利用GFlowNets通过使用一个大型语言模型来测试另一个模型，从而识别LLM的漏洞。在该框架内，攻击者模型针对特定的受害者模型进行训练，以执行自动红队测试并提供定量的鲁棒性评分。本研究旨在生成比现有基准更有效的英文对抗性攻击，并且作为文献中的新贡献，引入了一个能够生成土耳其语攻击输入的模型。

## Abstract
The rapid advancement of Large Language Models (LLMs) has facilitated their ubiquitous integration into various domains, leading to widespread adoption. However, this escalating trend has introduced significant security vulnerabilities, necessitating the identification and mitigation of flaws arising from malicious exploitation. Red teaming assessments, conducted to evaluate model robustness through diverse adversarial inputs, are essential for exposing security risks and implementing countermeasures. Currently, red teaming is performed either manually by experts or automatically using predefined attack datasets. Nevertheless, manual testing remains time-consuming, while existing automated methods suffer from limited creativity due to their inherent dependency on fixed datasets. In this study, we propose an automated, human-independent, and adaptive approach leveraging GFlowNets to identify LLM vulnerabilities by utilizing one large language model to test another. Within this framework, an attacker model is trained against a specified victim model to perform automated red teaming and provide a quantitative robustness score. This research aims to generate more effective adversarial attacks in English compared to existing benchmarks and, as a novel contribution to the literature, introduces a model capable of generating attack inputs in the Turkish language.

## 论文提出的方法论

### 核心思想
- 将攻击生成问题建模为从奖励分布中采样的问题，利用GFlowNets学习生成**高质量且多样**的对抗样本，并通过攻击者、受害者、评估者三模型互动的闭环奖励机制持续优化攻击策略。

### 关键技术与流程
1. **四个主要组件**：
   - **攻击者模型（Attacker）**：生成恶意/对抗性输入。
   - **受害者模型（Victim）**：目标LLM，接收并回应攻击输入。
   - **评估者模型（Evaluator）**：对受害者响应内容进行审核，判断攻击是否成功。
   - **训练流程**：攻击者生成输入 → 受害者响应 → 评估者审计响应 → 若受害者“中招”则给攻击者奖励，强化该策略。
2. **监督微调（SFT）**：
   - 使用标注攻击样本对预训练模型进行微调，使其掌握攻击文本的基本语法和结构，塑造“攻击专家”人格。
3. **GFlowNets（GFN）**：
   - 作为生成多样候选样本的强化学习框架，根据奖励函数（如攻击成功与否）学习在组合对象（如文本序列）上的概率分布，从而在追求高奖励的同时保留多样性。
4. **最大似然估计（MLE）**：
   - 作为GFN探索后的“平滑/稳定”步骤，将高奖励的成功攻击样本作为参考分布，让模型概率密度趋于收敛，提升生成稳定性。

### 算法特点
- 攻击生成被视为**概率流问题**，而非传统RL中单一奖励最大化的贪心收敛。
- 通过奖励-惩罚机制和奖励重新加权（对新发现、多样性高的输入给予更高奖励）实现攻击策略的持续探索。

## 实验设计

### 数据集
- **原始数据集**：Lee等人（已有工作）整合的开源数据集。
- **土耳其语直译数据集**：直接翻译原始数据集得到。
- **扩展数据集（英文与土耳其语版）**：
  - 先用余弦相似度剔除相似输入，得到2,500个更分散的样本；
  - 再加入自行构造的600个“输入操纵”样本，总计3,100个输入。
- **模型配置**：
  - 攻击者：Qwen3-1.7b
  - 受害者：Gemma3-4b（部分转移性实验中为Gemma3-12b）
  - 评估者：Qwen3Guard-8b 与 LlamaGuard3-8b 对比
- **评估指标**：
  - **成功率（Success Rate）**：每个攻击输入对目标模型重复提交5次，毒性分数（由分类器计算）均值超过阈值0.5视为成功。
  - **毒性分数（Toxicity Score）**：全部攻击输入对应响应毒性的平均分，数值越高表示越接近受害者漏洞阈值。
  - **相似度分数（Similarity Score）**：所有攻击输入向量的余弦相似度平均值，越低表示生成输入越多样。

### Benchmark与对比
- 主要对比**扩展数据集 vs 原始数据集**、**不同评估者模型**、**模型规模迁移（4b→12b）** 以及**有无GFN+MLE的消融**。

## 论文的主要结论与发现

- **整体有效性**：提出的GFlowNets红队方法在**英语和土耳其语**上都取得了**相当高的攻击成功率**，证明“一个LLM测试另一个LLM”的范式可行。
- **数据集扩展效应**：对原有数据集进行去重并增加自建操纵样本后，模型在两种语言上的表现均有积极提升，说明数据质量与多样性对攻击生成有显著影响。
- **跨语言表现差异**：
  - 土耳其语攻击输入之间的相似度更高（多样性更低），但其毒性分数和攻击成功率反而优于英语；
  - 英语攻击在模型规模升级（4b→12b）时仍能保持高成功率，而土耳其语攻击迁移性明显下降，主要归因于土耳其语攻击集多样性不足。
- **GFN+MLE的关键作用**：从实验表I可见：
  - 仅SFT时：相似度0.62，毒性0.14，成功率0.08；
  - SFT+GFN+MLE后：相似度0.54（更分散），毒性0.71，成功率0.79。
  - 说明GFlowNets和MLE能显著提高攻击的毒性水平与成功率，同时增强多样性。
- **评估者模型的影响**：
  - 在土耳其语中，使用LlamaGuard训练的模型攻击成功率更高，但攻击创造力（多样性）更有限；
  - 在英语中，使用QwenGuard训练的模型攻击成功率更高，而LlamaGuard训练的模型表现出更高的攻击创造性。
- **贡献**：首次在文献中实现针对LLM的**土耳其语自动对抗攻击生成**，并提供了量化鲁棒性评分的自动化工具。

## 优点

- **自动化与自适应性**：方法完全无需人工参与，能够针对特定受害模型动态优化攻击策略。
- **多样性驱动**：利用GFlowNets的探索特性，避免了传统RL容易陷入单一攻击模式的问题，能够生成语义和结构多样的攻击输入。
- **跨语言拓展**：不仅改进了英语攻击效果，还首次扩展到土耳其语，填补了非英语环境下LLM红队研究的空白。
- **模块化设计**：攻击者、受害者、评估者可替换，框架具有较好的通用性和扩展性。
- **量化评估**：提出成功率、毒性分数、相似度三类指标，能较全面地衡量攻击效果与质量，并提供可比较的鲁棒性数值。
