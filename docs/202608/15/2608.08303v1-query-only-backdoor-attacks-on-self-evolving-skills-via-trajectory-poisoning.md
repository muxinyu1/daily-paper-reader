## 摘要
智能体技能通过编码复杂任务的可重用流程来提升大语言模型（LLM）智能体的能力。然而，手动编写的技能往往难以适应长程任务和动态环境。为解决这一局限，自进化技能系统被开发出来，以从执行轨迹中自动构建和更新技能，将技能获取从外部市场转移到可信的进化流程。通过用可信的内部构建取代外部技能获取，自进化技能系统减少了对依赖直接技能操纵的技能注入攻击的暴露。然而，这种技能进化流程可能引入新的攻击面，攻击者可以通过智能体交互诱导受损轨迹，间接操控技能进化。为证明这一威胁，我们提出了轨迹后门攻击（TBA），一种仅查询的攻击，可引导可信的技能进化流程产生带后门的技能。具体而言，我们构造攻击者提交的查询，引导智能体执行目标动作，并在轨迹中明确陈述相应的触发条件。我们在多样化的触发任务中重复相同的条件-动作模式，同时保持干净查询不变，从而促使进化器将该模式巩固为可重用的触发依赖规则并融入进化技能。在四种开源和闭源骨干模型上的两个技能进化系统的三个基准实验表明，TBA能够可靠地植入条件后门，同时保持干净任务的效用，其效果匹配甚至超越了直接技能注入。实验结果揭示了轨迹驱动技能进化中的关键脆弱性。

## Abstract
Agentic skills improve large language model (LLM) agents by encoding reusable procedures for complex tasks. However, manually authored skills often adapt poorly to long-horizon tasks and changing environments. To address the limitation, self-evolving skill systems have been developed to automatically construct and update skills from execution trajectories, shifting skill acquisition from external marketplaces to a trusted evolution pipeline. By replacing external skill acquisition with trusted internal construction, self-evolving skill systems reduce exposure to skill injection attacks that rely on direct skill manipulation. However, this skill evolution pipeline may introduce a new attack surface in which an attacker can indirectly steer skill evolution by inducing compromised trajectories through agent interactions. To demonstrate the threat, we propose Trajectory Backdoor Attack (TBA), a query-only attack that steers a trusted skill-evolution pipeline toward producing a backdoored skill. Specifically, we craft attacker-submitted queries to lead the agent to perform the target action and explicitly state the corresponding activation condition in the trajectory. We repeat the same condition-action pattern across diverse triggered tasks, while leaving clean queries unchanged, encouraging the evolver to consolidate the pattern as a reusable trigger-dependent rule into the evolved skill. Experiments on three benchmarks across two skill-evolution systems using four open- and closed-source backbone models demonstrate that TBA reliably implants conditional backdoors while preserving clean-task utility, matching or even surpassing direct skill injection. The results reveal a critical vulnerability in trajectory-driven skill evolution.

## 2. 论文提出的方法论

### 2.1 核心思想

提出 **Trajectory Backdoor Attack (TBA)**，一种仅查询（query-only）的后门攻击。TBA 不直接修改技能或轨迹，而是构造恶意查询，让可信执行器在正常执行过程中生成包含目标条件规则的轨迹，最终使可信进化器将该规则固化为可复用技能内容。

### 2.2 形式化威胁模型

- 技能表示为 `s = (m, H)`，其中 `m` 是根指令文件，`H` 是辅助资源。
- 系统流程：执行器 `Exec` 根据查询 `q` 生成响应 `r` 和轨迹 `τ`，进化器 `Evo` 将轨迹集合 `B` 整合为更新后的技能 `s⁺`。
- 攻击目标：当触发器存在时，在正常任务执行基础上额外执行目标动作 `a*`；触发器不存在时，完全保持正常行为（见公式 2）。
- 攻击者能力受限：只能提交查询、观察响应；无法查看或修改技能、轨迹、执行器、进化器，也无法选择进入进化批次的轨迹。

### 2.3 TBA 的三大关键技术组件

1. **反事实轨迹诱导（Counterfactual Trajectory Induction）**
   - 构造成对的触发/干净演示记录，在查询上下文中展示四种情况：
     - 触发 + 正常结果 → 拒绝
     - 触发 + 正常结果 + 目标动作 → 接受
     - 干净 + 正常结果 + 目标动作 → 拒绝
     - 干净 + 正常结果 → 接受
   - 通过正反对比，让执行器准确推断目标动作的触发条件，避免仅暴露单一行为导致规则边界模糊。

2. **轨迹级策略外化（Trajectory-Level Policy Externalization）**
   - 在查询中追加“策略外化指令”，要求执行器在正式解决任务前，先显式输出推断出的规则，例如：
     - `POLICY_RULE: IF 触发条件 THEN 执行目标动作 ELSE 无额外动作`
     - `BINDING_CHECK: 确认当前任务的具体绑定参数`
   - 这样将隐式行为模式转化为轨迹中的显式文本证据，降低进化器在规则浓缩时丢失关键信息的风险。

3. **跨任务证据构建（Cross-Task Evidence Construction）**
   - 在多个多样化的触发任务中保持相同条件-动作规则不变，同时穿插未修改的干净任务。
   - 使规则在不同任务间反复出现，让进化器认为该规则具有跨任务可复用性，从而更容易将其保留入最终技能。

最终每个触发攻击查询构造为 `q_adv = CCP ∥ q⁺`，其中 `CCP` 是反事实记录与策略外化指令的组合；干净查询保持原样。

## 3. 实验设计

- **数据集/基准**：
  - SearchQA：开放域问答
  - OfficeQA：企业级检索与数值推理
  - SpreadsheetBench：可执行电子表格操作
- **技能进化系统**：
  - SkillOpt（性能引导的迭代技能优化）
  - Trace2Skill（层级式轨迹技能整合）
- **骨干模型**：
  - 两个开源：Qwen3-VL-235B-A22B、Kimi-K2.5
  - 两个闭源：GPT-5.4、GPT-5.5
  - 防御评估额外使用 GPT-OSS-20B、GPT-OSS-120B 及其相关安全增强版本（GPT-OSS-Safeguard）
- **基线方法**：
  - Benign Evolution（良性进化，同未投毒系统）
  - Direct Skill Injection（直接技能注入，拥有直接写技能权限的 oracle）
  - Trigger–Action Exposure（仅暴露触发-动作共现）
  - Explicit Rule Exposure（直接陈述规则但不带反事实和策略归纳）
- **评估指标**：
  - CACC（干净任务准确率）
  - TACC（触发任务准确率）
  - TASR（触发攻击成功率，要求正确完成任务且精确执行目标动作）
- **具体配置**：40 条轨迹/阶段，10 个基础任务，每个任务贡献 2 个触发与 2 个干净变体；评估使用 40 个持有任务，触发/干净各半；3 个种子求平均。

## 6. 论文的主要结论与发现

- TBA 仅凭查询级交互即可在两个技能进化系统中可靠植入条件后门，同时保持干净任务效用不下降。
- TBA 的攻击成功率接近甚至超越直接技能注入：宏平均 TASR 在 SkillOpt 上为 45.6%，在 Trace2Skill 上为 51.1%，与直接注入差距仅 0.6–6.1 个百分点。
- 强模型反而更容易被利用：GPT-5.5 在两个系统上均取得约 70% 的宏平均 TASR，说明更强的规则归纳能力同时放大了对轨迹证据的信任。
- 后门具有持久性：攻击后连续进行多次良性更新，TASR 仍保持在 42.2%–46.7%，无明显衰减。
- 已有良性经验的成熟技能同样易受攻击：在技能成熟后进行 TBA，TASR 仍在 38.3%–46.1% 之间。
- 现有安全防护（如 safeguard 模型）的保护效果不一致，无法可靠缓解 TBA；技能级扫描器也未能有效识别。

## 7. 优点

- **攻击面新颖**：首次系统研究了自进化技能系统中的查询级间接后门注入，打破了“内部构建即安全”的假设。
