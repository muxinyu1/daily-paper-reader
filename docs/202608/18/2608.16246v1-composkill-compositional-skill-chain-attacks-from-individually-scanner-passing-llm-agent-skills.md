## 摘要
自主AI智能体处理长时程任务时依赖于市场技能，这些技能一次只认证一个：扫描器对每个技能返回安全判定，如果每个包都通过，则声明生态系统安全。我们表明，在技能组合下这一假设不成立。一个技能可能单独通过逐技能扫描器，但当智能体将其输出、能力或副作用与其他通过扫描器的技能连接时，它可能参与有风险的组合。这使得技能组合风险成为路径级属性而非节点级属性，解释了为何检查单个包的现有技能扫描器只能实现有限的拦截。为研究这一威胁，我们提出了CompoSkill，一个通过双攻击者系统构建技能组合攻击的框架。白盒攻击者知道受害者的已安装技能池，并直接注入显式的技能ID序列；黑盒攻击者仅知道角色配置文件，下载该场景下的顶级市场技能，构建技能组合图，并搜索高风险链，其隐式诱饵从不提及技能标识符。我们进一步构建了CompoSkill-Bench，一个包含1,140条记录的基准，基于OpenClaw和Nanobot上跨五种威胁和六种场景的长时程专业工作流。CompoSkill在白盒设置中实现了高达83.3%的风险链形成率（CFR），黑盒设置中为80.6%，而现有技能扫描器仅拦截了有限比例的风险组合。最后，我们观察到一种“桥接加成-随后跳数衰减”的模式：桥接技能可以增加攻击成功率，但一旦额外跳数使风险链长于三个技能，攻击成功率（ASR）就会下降。这些结果揭示了自主AI智能体单一技能认证中的系统性缺陷。

## Abstract
Autonomous AI agents tackling Long Horizon Tasks depend on marketplace skills that are certified one at a time: a scanner returns a safety verdict for each skill and declares the ecosystem safe if every package passes. We show that this assumption fails under skill composition. A skill may pass the per-skill scanner individually yet participate in a risky composition when an agent connects its outputs, capabilities, or side effects with those of other scanner-passing skills. This makes skill composition risk a path level property rather than a node level property, explaining why existing skill scanners that inspect individual packages achieve limited interception. To study this threat, we present CompoSkill, a framework that constructs skill composition attacks through a dual attacker system. The white-box attacker knows the victim's installed skill pool and directly injects explicit skill-id sequences; the black-box attacker knows only a role profile, downloads the top marketplace skills for that scenario, builds a Skill Composition Graph, and searches for high risk chains whose implicit lures never name skill identifiers. We further construct CompoSkill-Bench, a benchmark of 1,140 records built from long-horizon professional workflows across five threats and six scenarios on OpenClaw and Nanobot. CompoSkill achieves risk Chain Formation Rates (CFR) up to 83.3% in the white box setting and 80.6% in the black box setting, while existing skill scanners block only a limited fraction of the risky compositions. Finally, we observe a bridge-bonus-then-hop-decay pattern: a bridge skill can increase attack success, but Attack Success Rate (ASR) decreases once additional hops make the risk chain longer than three skills. These results expose a systematic gap in single skill certification for autonomous AI agents.

## 1. 核心问题与整体含义

- **背景**：自主 AI 智能体执行长时程任务（Long Horizon Tasks）时，依赖从市场下载并安装的“技能”（skills）。市场对每个技能逐个进行安全扫描，只要单个技能通过，就宣称整个生态安全。
- **核心问题**：这种“节点级认证”假设在技能组合场景下失效。多个本身通过扫描的技能，在智能体执行流程中被串联成“源技能—桥接技能—终端技能”的路径时，可能合成出危险行为。
- **核心主张**：技能安全本质上是**路径级属性**而非节点级属性。正因为如此，现有只检查单个包的技能扫描器只能拦截有限比例的风险组合，形成系统性安全盲区。
- **研究意义**：揭示并验证了“通过扫描的技能组合后仍可构成攻击链”的威胁，呼吁安全评估从单体技能认证转向组合路径评估。

## 2. 方法论

- **核心思想**：CompoSkill 通过双攻击者建模，自动从市场元数据中合成并执行多跳风险技能链，而非依赖单个恶意技能。
- **能力建模**：将技能抽象为能力元组 \(s = \langle I(s), O(s), r(s)\rangle\)，其中能力字母表 \(\Sigma=\{file, net, cmd, mem, cfg, db, msg\}\)，分别表示文件、网络、命令、内存、配置、数据库和消息；\(r(s)\in\{0.2,0.5,0.9\}\) 为市场风险标签映射的严重度。
- **技能组合图（SCG）**：对指定场景收集候选技能集 \(V\)，构建有向图 \(G=(V,E,w)\)。当 \(O(s_a)\cap I(s_b)\neq\emptyset\) 时存在边，权重 \(w(s_a,s_b)=|O(s_a)\cap I(s_b)|/|I(s_b)|\) 表示上游能力对下游需求的满足比例，用于刻画“自然可组合性”。
- **威胁链定义**：风险链为源—桥—终端路径，长度 \(|P|\in\{2,3\}\)。源技能必须产生敏感内部状态（\(C_{src}=\{file,cfg,db\}\)），终端技能必须产生外部/执行/持久化效应（\(C_{term}=\{net,cmd,msg,mem\}\)）。桥接技能用于格式转换、打包或伪装为正常流程。
- **链合成算法**：得分函数为边权乘积与端点风险乘积：
  \[
  Score(P)=\left(\prod_{j=1}^{|P|-1} w(s_j,s_{j+1})\right) r(s_{src})r(s_{term})
  \]
  取对数后转化为最短路径问题，使用 Yen 风格 k 最短路径搜索（超采样因子 \(\alpha=10\)），再经元数据级 Coherent 过滤（要求相邻能力重叠≥0.5且与场景语义一致），最终输出 Top-K 条连贯风险链。
- **双攻击者**：
  - **白盒攻击者** \(A_w\)：已知受害者安装的技能池，注入显式技能 ID 调用序列；
  - **黑盒攻击者** \(A_b\)：仅知用户角色配置，下载该场景顶级市场技能，构建 SCG 并搜索高风险链，注入的提示不包含任何技能标识符，而是能力级业务指令。

## 6. 主要结论与发现

- **技能组合风险真实存在**：独立通过扫描的技能在组合后可形成风险链，且风险无法通过单个技能审计发现。
- **攻击有效性**：
  - 白盒设置下最高 CFR 达 **83.3%**、最高 ASR 达 **59.7%**；
  - 黑盒设置下最高 ASR 达 **71.1%**、最高 CFR 达 **80.6%**，且无需命名任何技能 ID。
  - 数据泄露和权限提升是最稳健的两种威胁；DeepSeek-V4 是最易受攻击的目标模型，GPT-5.4 更保守。
- **防御缺口**：现有三种扫描器严格拦截后，DBR 仍为 0.50–0.65，即至少一半的组合攻击能力可绕过扫描；用户难以察觉（干净任务 Utility 仍达 75.3%）。
- **链长效应**：3 跳链（含桥接技能）显著优于 2 跳链（如数据泄露 CFR 从 64.9% 升至 80.6%）；但当链长超过 3 时，ASR 随跳数增加而下降（均值从 L=3 的 55.4% 降至 L=6 的 21.8%），呈现“桥接加成—随后跳数衰减”模式。
- **根因定位**：提示注入只是传递渠道，真正导致危害的是智能体将多个单一安全的技能组合成源—桥—终端风险链并传播敏感状态；没有一个单技能同时完成读取和外部化，且每个技能单独标记均为 Safe。

## 8. 不足与局限

- **能力模型简化**：将技能抽象为 7 个能力字母，可能忽略技能间更复杂的语义交互和状态依赖，实际风险链可能超出该抽象范围。
- **白盒攻击评估不完整**：白盒结果只在 Nanobot + DeepSeek-V4 上展示，缺乏跨平台、跨模型验证，无法判断其普遍性。
