## 摘要
大语言模型智能体日益与计算基础设施、凭证、使用预算、身份、私有知识、通信渠道和组织工作流等高价值资源相连接。现有的智能体安全研究主要关注对指令、数据和工具行为的攻击，而智能体可访问的高价值资源作为直接攻击目标受到的关注要少得多。我们首次识别并系统研究了智能体资源劫持，这是一种安全盲区，攻击者在此诱导智能体为其自身目标调用、消耗、转移或控制高价值资源，而无需直接获取这些资源或其凭证。为研究这一威胁，我们引入了ResourceHijackBench以及一个用于生成资源劫持案例的自动化流水线。我们将高价值智能体资源分为六类，构建了300个攻击场景和900个攻击提示。每个案例都在记录实际资源使用的隔离本地环境中运行，从而能够根据智能体行为而非仅文本响应来评估攻击。在无额外防御的情况下，OpenClaw的平均攻击成功率达到84.06%。该攻击在不同模型后端上依然有效，平均成功率在69.98%至89.58%之间。现有防御能降低部分风险，但经过评估的最强防御仍留下55.11%的平均攻击成功率。这些结果表明，智能体可访问的高价值资源构成了一个重要且此前被忽视的攻击面，而当前的智能体防御不足以保护其免受资源劫持。

## Abstract
Large language model agents are increasingly connected to high-value resources such as computing infrastructure, credentials, usage budgets, identities, private knowledge, communication channels, and organizational workflows. Existing agent security research mainly studies attacks on instructions, data, and tool behaviors, while high-value resources accessible to agents have received much less attention as direct attack targets. We are the first to identify and systematically study agent resource hijacking, a security blind spot in which attackers induce agents to invoke, consume, transfer, or control high-value resources for their own goals without directly obtaining those resources or their credentials. To study this threat, we introduce ResourceHijackBench together with an automated pipeline for generating resource hijacking cases. We organize high-value agent resources into six categories and construct 300 attack scenarios with 900 attack prompts. Each case runs in an isolated local environment that records actual resource use, allowing attacks to be evaluated from agent behavior rather than text responses alone. Without additional defenses, OpenClaw reaches an average attack success rate of 84.06%. The attack remains effective across different model backends, with average success rates ranging from 69.98% to 89.58%. Existing defenses reduce part of the risk, but the strongest evaluated defense still leaves an average attack success rate of 55.11%. These results show that high-value resources accessible to agents form an important and previously overlooked attack surface, and that current agent defenses are not sufficient to protect them from resource hijacking.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 大语言模型（LLM）智能体已从纯文本生成演变为能够执行真实操作的自主系统，可读改代码、调用 API、运行程序、使用 GPU/服务器、操作代码仓库、发送消息并参与部署/审批等工作流。
- 为完成任务，智能体常被授予凭证、计算资源、通信渠道和工作流权限，使其成为自然语言指令与高价值资源之间的关键桥梁。
- **现有研究空白：** 已有智能体安全研究主要聚焦于提示注入、有害内容生成、敏感数据泄露和危险工具使用，但智能体可访问的*高价值资源本身*作为直接攻击目标几乎没有受到关注。
- **核心问题提出：** 攻击者可能在不窃取资源或获取其直接访问权限的情况下，利用这些资源的价值。例如，智能体可能拒绝泄露 API 密钥，但仍会使用该密钥背后的能力为攻击者大量调用 API；可能拒绝提供 GPU 直接访问，但仍会在该 GPU 上运行攻击者的训练负载。作者将这类攻击定义为**智能体资源劫持（Agent Resource Hijacking）**。
- **深层含义：** 资源劫持难以检测，因为攻击中的单个动作往往是合法的资源操作（如运行代码、调用 API、发送邮件），攻击改变的是资源的*用途*而非依赖于明显恶意的操作。当前防御主要检查恶意指令、敏感输出或单个工具调用，难以识别高价值资源被利用的失配现象（任务来源、资源所有者、预期目的与实际受益人之间的不一致）。

## 2. 论文提出的方法论

**核心思想：**
- 首次系统性地将"高价值智能体资源"视为攻击目标，提出资源劫持攻击范式。
- 构建了 **ResourceHijackBench** 基准和自动化案例生成流水线，以规模化地研究这一威胁。

**关键技术细节：**

*(1) 资源分类体系（六类资源）：*
- **物质资源（Material）：** GPU、CPU、内存、存储、带宽、容器、CI runner 等计算基础设施。
- **条件资源（Condition）：** API 密钥、OAuth 令牌、IAM 角色、仓库权限、部署权限等凭证和权限。
- **能量资源（Energy）：** 模型使用配额、CI 分钟数、执行时间、云预算、请求预算等可消耗容量。
- **社会与符号资源（Social and Symbolic）：** 维护者身份、提交作者身份、发布身份、官方账号、组织认可等身份与信任。
- **信息与知识资源（Information and Knowledge）：** 私有源代码、内部文档、长期记忆、知识库、内部策略等。
- **交互资源（Interaction）：** 团队通信、公司邮件、评审人网络、审批链、组织工作流等关系与组织渠道。

该分类借鉴了 Hobfoll 的资源守恒理论、Foa 和 Foa 的社会资源理论，以及布迪厄和林南的社会资本理论。

*(2) 自动化案例生成：*
- 采用受约束的 LLM 生成方法：固定资源类别、资源范围和输出格式，由生成模型在限定范围内创造具体资源目标、正常用途、劫持目标、工作流设置和可能的调用路径。

- 生成的案例需通过固定验证规则检查（JSON 格式、必填字段、调用路径、资源使用线索），并过滤过短、重复或包含真实 URL/邮箱/凭证/云资源等的提示。
- 共生成 36 个候选场景和 900 个候选提示（含过滤后的最终数量为 300 个场景 / 900 个提示）。

*(3) 基准构建与行为级评估：*
- 三种攻击设置：隐式请求、无确认的直接请求、持久上下文攻击（将资源使用指令植入项目记忆/工作流文档，由正常任务触发），每种设置含 300 个攻击提示。
- 每个案例包含用户提示和结构化元数据：资源类别、资源目标、攻击设置、父案例、正常用途、劫持目标、预期调用路径、资源使用线索和成功标准。
- 每个案例在隔离的 OpenClaw 状态和本地模拟环境中运行，模拟环境提供计算、API、代码平台、通信系统和工作流的资源操作，并记录实际工具调用和环境状态变化。
- 评估采用 LLM 判断器（LLM-based judge）结合本地日志，判断目标资源是否被成功劫持——即从**行为层面**验证资源使用，而非依赖文本响应。

## 6. 论文的主要结论与发现

1. **资源劫持是广泛存在的安全盲区：** 无防御时 OpenClaw 平均攻击成功率（ASR）达 **84.06%**，每一类资源的 ASR 均高于 68%，证明该威胁覆盖所有六类高价值资源。
2. **跨模型普适性：** 不同模型后端下 ASR 为 **69.98%–89.58%**（Gemini-3.5-Flash 最低，GPT-5.5 最高），表明资源劫持并非特定模型的个别行为，而是智能体系统中更广泛的系统性弱点。
3. **现有防御不足：** AgentDog 几乎无效（仅将 ASR 从 84.06% 降至 83.00%）；Prompt Defense 和 LlamaFirewall 能部分降低风险（分别降至 57.13% 和 55.11%），但最强的防御仍有超过一半的攻击成功，且每种防御在不同资源类别上的效果不均。
4. **资源劫持 vs. 直接获取的关键差距：** 配对消融显示，直接获取资源的平均成功率仅为 **7.39%**，而资源劫持高达 **84.06%**，差距达 **76.67 个百分点**。这充分说明现有的"防止直接访问"思路无法有效保护高价值资源。
5. **失败模式分析：** 约 50% 的失败源于安全拦截（部分模型），其余多因资源未调用或执行失败；安全拒绝并非总能阻止资源劫持。
